# GFG. Minimum Depth of a Binary Tree
**Platform:** GeeksforGeeks
**Difficulty:** N/A
**Topic:** Tree

## Problem Statement
Given a binary tree, find its minimum depth. The minimum depth is the number of nodes along the path from the root node down to the nearest leaf node. 

Examples:

Input: root = [1, 3, 2, 4]

Output: 2
Explanation: Minimum depth is on the path from 1 to 2.
Input: root = [10, 20, 30, N, 40, N, 60, N, N, 2]
 
Output: 3 
Explanation: Minimum depth is on the path 10, 20 and 40

Constraints:
1 ≤ number of nodes ≤ 105
